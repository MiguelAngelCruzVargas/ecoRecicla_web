# 🌿 EcoRecicla Web 2026 | Sostenibilidad Escolar

¡Bienvenido/a al repositorio de **EcoRecicla Web**! Un portal educativo interactivo, moderno y de alto impacto visual diseñado para concientizar sobre el cuidado ambiental y promover el reciclaje en el ámbito escolar y comunitario.

Este proyecto destaca por una interfaz premium que busca cautivar al usuario desde el primer vistazo, implementando dinámicas avanzadas y micro-animaciones en un diseño completamente responsivo y adaptativo.

---

## ✨ Características Principales

*   **🌊 Barra de Navegación "Liquid Glass":** Una cabecera flotante en pantalla completa con efecto de vidrio esmerilado, gradientes de color dinámicos, indicador de progreso de scroll integrado con brillo y menús desplegables estilo "gota de agua" (*droplet dropdowns*) con transiciones ultra fluidas.
*   **🖱️ Cursor Personalizado de Reciclaje:** Reemplazo inteligente del cursor del navegador por un ícono de reciclaje animado que interactúa con hover dinámico sobre elementos seleccionables para mejorar el engagement del usuario.
*   **📊 Guía de Clasificación de Residuos:** Una infografía interactiva de alto rendimiento con botes en 3D/ilustrativos y etapas informativas en 3D neumórficas para facilitar la separación de Plásticos, Cartón/Papel, Vidrio y Residuos Especiales.
*   **🎮 Clasificador Rápido Escolar (Juego Bento):** Un mini-juego interactivo en un diseño estilo Bento Box donde los estudiantes pueden poner a prueba sus conocimientos de separación y obtener retroalimentación instantánea.
*   **📱 Diseño Totalmente Responsivo:** Diseñado meticulosamente para verse impecable tanto en dispositivos móviles compactos como en portátiles de 14 pulgadas y pantallas de escritorio grandes.
*   **⚡ Alto Rendimiento y Estética:** Optimizado con propiedades aceleradas por GPU, fuentes premium (Plus Jakarta Sans), iconos dinámicos (FontAwesome) y paletas de colores cuidadosamente seleccionadas.

---

## 🛠️ Tecnologías Utilizadas

1.  **HTML5:** Estructura semántica completa para una óptima accesibilidad y SEO.
2.  **Tailwind CSS:** Diseño visual fluido mediante estilos utilitarios modernos y limpios.
3.  **JavaScript Vanilla:** Lógica del cliente ágil y libre de frameworks pesados para animaciones premium, la interactividad del juego Bento, control del cursor y efectos del navbar.
4.  **FontAwesome v6:** Kit de iconos vectoriales interactivos.
5.  **Google Fonts:** Tipografía *Plus Jakarta Sans* para una lectura cómoda y un acabado tipográfico de alta gama.

---

## 🚀 Instalación y Uso Local

Este proyecto no requiere procesos complejos de compilación en su forma actual, ya que utiliza Tailwind CSS optimizado para producción. Para ejecutarlo localmente:

1. Clona este repositorio:
   ```bash
   git clone https://github.com/MiguelAngelCruzVargas/ecoRecicla_web.git
   ```
2. Abre la carpeta del proyecto en tu editor preferido (por ejemplo, VS Code):
   ```bash
   cd ecoRecicla_web
   ```
3. Ejecuta el archivo principal abriendo `index.html` directamente en tu navegador o utilizando una extensión de servidor local como *Live Server*.
